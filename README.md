# Learn Playwright 2X

Learning Playwright automation with JavaScript.

## Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later)
- npm (comes with Node.js)

## Setup

```bash
# Install Playwright
npm install -D @playwright/test

# Install browsers
npx playwright install
```

## Contents

| Chapter | Topic |
|---------|-------|
| Chapter 1 | JavaScript Basics |
| Chapter 2 | JavaScript Concepts |

### Chapter 1 - JavaScript Basics

- `basics.js` - Hello World, platform, architecture, and Node.js version
- `lab5.js` - Variable declaration and hoisting with `var`

## Running

```bash
node chaper_01_Javabasic/basics.js
node chaper_01_Javabasic/lab5.js
```
